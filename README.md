# Make the AI Judge Feel Nostalgic

A deterministic Python entry for the [Make the AI Judge Feel Nostalgic](https://make.fun/bounty/u-shino-make-the-ai-judge-feel-nostalgic-a-childhood-625d3363) competition on make.fun. The program writes the entry text to `entry.txt`, with no trailing newline. The readable source is `entry_source.py`; `main.py` is the official make.fun compress output of that source.

## Running

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```

If `MAKEFUN_OUTPUT_DIR` is not set, the entry is written to `/output/entry.txt`.
